Plant Disease Monitoring

This project uses Convolutional Neural Networks (CNN) to analyze leaf images and detect plant diseases automatically.

About the System

The plant monitoring module allows farmers to upload crop leaf images. The AI model analyzes the visual patterns in leaves and identifies diseases such as Early Blight or Late Blight.

Key Features

  • Deep learning based disease detection
  • Image classification using CNN
  • Automated diagnosis
  • Fast and accurate predictions
